# Recruiter pack

A short route through the project for hiring managers, recruiters and interviewers. **All data are synthetic**; this is an independent portfolio project, not a company project.

## A. Project overview in 60 seconds

**What it is.** An end-to-end analytics case study on a fictional Indian retail brokerage (10,000 synthetic customers, Nov 2025 – Oct 2026): data audit and cleaning, funnel, acquisition, campaign, retention, segmentation and support analysis in SQL, Python and Excel; a Power BI build kit; a growth plan with 15 recommendations and 10 proposed experiments; and a Streamlit prototype that flags customers stuck in onboarding.

**What it shows about me.**

| Skill | Evidence |
|---|---|
| Structured problem-solving | Business problem → questions → modules → recommendations |
| SQL | 34 queries on SQLite incl. window functions, cohorts, medians without `MEDIAN()` ([`04_sql/`](../../04_sql/)) |
| Python | Reusable package, one-command pipeline, 5 executed notebooks ([`05_python/`](../../05_python/)) |
| Excel | Live-formula workbook reconciled to Python (114 of 114) ([`03_business_analytics/excel/`](../../03_business_analytics/excel/)) |
| Data quality | 8 audit findings, 13 logged fixes, as-of correction for future-dated events ([`01_data_audit/`](../../01_data_audit/), [`02_data_cleaning/`](../../02_data_cleaning/)) |
| Product / growth analytics | Funnel leaks, cost per first trade, retention, segments ([`reports/final_project_report.md`](../../reports/final_project_report.md)) |
| Statistics | Wilson intervals, Holm correction, Mantel–Haenszel, power analysis ([`../methodology.md`](../methodology.md)) |
| Verification discipline | SQL = Python = Excel on 71 of 71 KPIs |
| Commercial judgement | Recommendations with owners, KPIs, risks and guardrails ([`07_growth_strategy/`](../../07_growth_strategy/)) |
| Honesty | Proxies labelled, no ROI claimed, mockups labelled, limitations listed ([`../limitations.md`](../limitations.md)) |

**What it deliberately does not claim.** No revenue or ROI (the data has none), no confirmed churn, no experiment results, no finished Power BI dashboard.
